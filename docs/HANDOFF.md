# Передача проекта разработчику

## Задача и ограничения

Учебная контрольная, вариант 8; описание на страницах 19–21 assignment.pdf, общие требования на странице 1. Обязательны Qt Widgets, форма Qt Designer, QGraphicsScene/QGraphicsView и QTimer. Не заменять форму программной сборкой интерфейса.

Пользователь уточнил: начинать миссию с базы; после сброса также возвращаться на базу; надпись «Связь: Есть»; обводка БПЛА совпадает с цветом заливки; скорость немного увеличена.

## Реализация

- Сцена: 600 × 400.
- База: (300, 200).
- Маршрут: (100, 100), (500, 100), (500, 300), (100, 300), далее повтор.
- Таймер: 50 мс; шаг: 4 единицы сцены; номинально 80 единиц/с. Физические метры не моделируются.
- Состояния: IDLE → MISSION → RTL → LANDED; сброс из любого состояния → IDLE.
- Для новой миссии после посадки нужен сброс.
- При достижении цели позиция устанавливается точно; при нулевом расстоянии деления нет.
- std::hypot заменяет ошибочное dir.length() для QPointF из методички.
- Линия RTL показывает путь от места обрыва до базы; скрывается при сбросе.
- Сцена и таймер принадлежат MainWindow через QObject-parent; графическими объектами владеет сцена.

## Состояние проверок

Исходники успешно компилировались напрямую MinGW 13.1.0 с библиотеками Qt 6.12.0. Автоматические проверки маршрута и RTL проходили в offscreen-режиме. Пользователь просмотрел и принял интерфейс.

Чистая сборка через CMake/Qt Creator и альтернативная сборка qmake пока не подтверждены. В исходной среде qmake не смог определить параметры компилятора; установленный Qt собран GCC 15.1, доступный MinGW был 13.1. Для передачи выбирать совместимый комплект, не копировать локальные пути и DLL. Подключение теста к CMake добавлено при подготовке передачи и отдельно не запускалось.
